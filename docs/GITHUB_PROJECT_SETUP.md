# GitHub project setup

## Suggested project fields

- Status: Backlog, Ready, In Progress, Validation, Done
- Milestone: the six roadmap milestones
- Work type: Product, Content, Engineering, Research, Safety
- Priority: P0, P1, P2

## Suggested labels

`product`, `content`, `frontend`, `backend`, `ai-tutor`, `analytics`, `accessibility`, `privacy`, `testing`, `documentation`, `P0`, `P1`, `P2`

## Repository controls

- Require pull-request review for protected control-layer files.
- Require the validation workflow before merging.
- Enable secret scanning and push protection where available.
- Disable direct production deployment, automatic merging, and broad third-party write access during the prototype.
- Tag stable pilot checkpoints for rollback.

GitHub stores the controlled specification and source code. It is not the student-record database or source-document archive.

# Learning design

## Learning loop

Diagnostic → recommendation → prediction → response → reasoning diagnosis → hint/explanation/retry/prerequisite → mastery update → next activity → delayed review.

## Mastery presentation

Named levels are primary: **Starting**, **Developing**, **Proficient**, and **Mastered**. A percentage may appear as secondary evidence, for example: “Proficient — 78% mastery.” Do not imply more precision than the evidence supports.

Cohort standing is calculated separately for each subchapter. Display it only after a minimum comparison group and comparable evidence threshold are met, using broad bands such as “Top 25% of students with comparable evidence.”

## Evidence model

Record first attempt separately from later assisted success. Evidence includes correctness, attempts, time on task, hints, revisits, and delayed review. Fast guessing must not outrank slower, well-supported reasoning.

## Motivation

Use XP, named mastery levels, learning streaks, and restrained achievements to support continuity. Avoid limited lives and high-pressure global leaderboards. Progress should remain recoverable after mistakes.

## Dynamic tutor

The tutor may explain, question, diagnose misconceptions, and create bounded variants. It must ground responses in the approved package plus standard prerequisites, disclose uncertainty, and hand off flagged content for instructor review.

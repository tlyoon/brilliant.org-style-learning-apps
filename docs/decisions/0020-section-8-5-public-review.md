# 0020 - Section 8.5 public review

Status: Accepted, 30 August 2026 by explicit project-owner deployment request

- The generated Section 8.5 package may be released as a public static review prototype alongside the existing Chapter 8 drafts.
- The deployment reuses the public GitHub Pages repository section-8-1-learning-app and gives Section 8.5 a distinct route and package path.
- Deployment does not change the package's draft status or supply physics, pedagogy, translation, accessibility, provenance, or publication sign-off.
- The public bundle contains only learner HTML, JavaScript, CSS, and the explicitly approved package JSON files.
- Repository history, specifications, tests, review records, source manifests, development tooling, credentials, controlled source material, run diagnostics, and Gemini responses remain excluded.
- The static review site stores no student records, credentials, analytics, raw audio, tutor transcripts, or production exports and instructs search engines not to index its pages.

This decision narrowly extends Decisions 0007 and 0018 and creates a public-review exception to Decision 0017's deployment prohibition for the Section 8.5 draft. Qualified human review continues to gate any status change or publication claim.

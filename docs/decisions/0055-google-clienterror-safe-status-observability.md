## Executable recurrence fix

Reuse `app_generator/llm/gemini_key_failover.py::error_status` (previously safe numeric `status_code/code`) and `app_generator/runtime/v3_gemini_diagnostics.py::classify_google_failure` instead of writing a second HTTP error mapper. New `sanitized_provider_failure_metadata` in `app_generator/validation/reviewer_failure_policy.py` records **only** `providerHttpStatus` as int 400..599 and canonical `providerFailureClass` for actual known provider exception classes. It never serializes the exception, its message, API payload, response text, prompt, credentials or metadata outside the private claim. Without a trustworthy numeric code it emits only `UNCLASSIFIED_PROVIDER_ERROR`.

The normal `assess_with_models` handler persists this sanitized diagnosis in its own immutable per-role private `AMBIGUOUS` claim and source-bound aggregate `UNRESOLVED` reviewer row. Strict `_validate_cached_review` has been extended to accept ONLY the exact optional safe keys, validate numeric-to-class consistency and reject any extra fields; science PASS still requires a separate exact-source valid two-reviewer decision. For known provider-side request rejections (400/401/403/404/429 or billing) the current activity **does not send its second reviewer request**: it writes a distinct `SKIPPED_UNSENT` `PROVIDER_REJECTION_UNSENT` state, preserving the first potentially submitted role, its SHA, and the reason why another call was not made. Only actual capacity cases use the earlier `PROVIDER_CAPACITY_UNSENT`. Restarts never replay submitted requests or silently upgrade these failures.

Default and restricted `provider_capacity_gate` now enforce the same standardized causes: 401/403 `BLOCKED_EXTERNAL_REVIEW_TRANSPORT`, 400 `STOP_PROVIDER_INVALID_MODEL_REQUEST`, 404 `STOP_PROVIDER_MODEL_NOT_FOUND`, 429 `STOP_PROVIDER_QUOTA_OR_RATE_LIMIT`, billing `STOP_PROVIDER_BILLING_RESTRICTED` and 5xx a finite capacity cooldown. The old genuinely unstamped `AMBIGUOUS ClientError` remains `STOP_UNCLASSIFIED_PROVIDER_REVIEW`; no provider trial is allowed on its existing original/new supplemental claim.

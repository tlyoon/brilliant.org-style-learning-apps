# 0007 — Section 8.1 dual-version public review

Status: Accepted, 26 August 2026

- The initial and regenerated Section 8.1 packages may be released together as public static review prototypes.
- The deployment uses a separate public repository named `section-8-1-learning-app`; the private development repository remains private.
- The root page identifies both packages as drafts and links to immutable Version 1 and Version 2 routes.
- Deployment does not change either package's `draft` status or supply any physics, pedagogy, translation, accessibility, provenance, or publication sign-off.
- The public bundle contains only learner runtime assets, two entry pages, and the two package JSON files.
- Repository history, specifications, tests, review records, source manifests, development tooling, credentials, controlled source material, run diagnostics, and Gemini responses are excluded.
- The static site stores no student records, credentials, analytics, raw audio, tutor transcripts, or production exports.

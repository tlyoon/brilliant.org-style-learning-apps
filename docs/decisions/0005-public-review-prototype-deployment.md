# 0005 — Public review-prototype deployment

Status: Accepted, 19 August 2026

- The development repository remains private.
- Section 1.1 may be released as a public, static GitHub Pages review prototype in a separate repository containing only the runtime bundle.
- The public bundle includes the learner HTML, JavaScript, CSS, and the Section 1.1 package; these files are intentionally retrievable by visitors.
- The bundle excludes repository history, specifications, tests, internal review records, source manifests, development tooling, and all sensitive or controlled source material.
- The deployed package remains in `review` status, carries a visible review-prototype notice, and does not acquire publication sign-offs through deployment.
- The prototype stores no student records, credentials, analytics, raw audio, tutor transcripts, or production exports.

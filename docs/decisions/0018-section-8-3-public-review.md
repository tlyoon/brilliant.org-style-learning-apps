# 0018 — Section 8.3 public review

Status: Accepted, 29 August 2026 by explicit project-owner deployment request

- The generated Section 8.3 package may be released as a public static review prototype alongside the two Section 8.1 drafts.
- The deployment reuses the existing public GitHub Pages repository `section-8-1-learning-app` to preserve its established URL and Section 8.1 routes; its landing page identifies the combined Chapter 8 review site.
- Section 8.1 Version 1 and Version 2 remain available at their existing immutable routes. Section 8.3 receives a distinct route and package path.
- Deployment does not change any package's `draft` status or supply physics, pedagogy, translation, accessibility, provenance, or publication sign-off.
- The public bundle contains only learner HTML, JavaScript, CSS, and the three package JSON files.
- Repository history, specifications, tests, review records, source manifests, development tooling, credentials, controlled source material, run diagnostics, and Gemini responses remain excluded.
- The static review site stores no student records, credentials, analytics, raw audio, tutor transcripts, or production exports and instructs search engines not to index its pages.

This decision narrowly extends Decisions 0005 and 0007 and creates a public-review exception to Decision 0017's deployment prohibition for the Section 8.3 draft. Qualified human review continues to gate any status change or publication claim.

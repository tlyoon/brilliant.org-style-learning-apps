# 0001 — Product scope

Status: Accepted, 15 August 2026

- Pilot: six subchapters of an instructor-selected undergraduate physics chapter.
- Mode: formative practice only.
- Audience: an instructor's class first; architecture remains reusable.
- Access: formal name and matric number under institutional controls.
- Progression: automatic unlocking with adaptive prerequisite routing.
- Package ownership: uploading instructor.
- Default sharing: private to the course.
- Commercial direction: hybrid institutional and student model, deferred beyond the pilot.

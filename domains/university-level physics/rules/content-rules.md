# University-level physics content rules

This domain extends the repository-wide content rules with physics-specific requirements.

- Preserve the current calculator-free conceptual emphasis unless project policy explicitly changes it.
- Physics representations may use vectors, free-body diagrams, motion/energy state representations, qualitative graphs, and bounded deterministic simulations.
- Direction, sign, relative magnitude, units, axes, state ordering, and declared physical invariants must agree with the question and answer logic.
- Do not invent apparatus, forces, trajectories, geometry, labels, or states that are not justified by the source, a trusted template invariant, or an explicitly declared pedagogical simplification.
- Answer-critical physics must be carried by deterministic renderer/simulation output; generated raster imagery is contextual only.
- Use independent symbolic/numerical verification for high-value relations when it materially reduces error risk.
